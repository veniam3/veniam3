# Veniam — GitHub Profile

## Before pushing

1. Rename this repository to exactly your GitHub username.
2. Open `README.md`.
3. Replace every occurrence of `YOUR_USERNAME` with your GitHub username.
4. Commit and push the files to the `main` branch.

GitHub automatically displays the root `README.md` on your profile when the public repository name matches your username.

## Files

- `README.md` — GitHub profile page.
- `veniam.css` — pastel pink CSS theme for a separate website. GitHub does **not** apply custom CSS to profile READMEs.
- `assets/buttons/README.md` — notes about the 88×31 buttons.
